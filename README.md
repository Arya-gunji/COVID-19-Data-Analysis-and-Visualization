# COVID-19 Data Analysis and Visualization

## Project Overview
This project focuses on analyzing and visualizing COVID-19 data using Python. It explores confirmed cases, deaths, recoveries, active cases, and country-wise statistics through data analysis and an interactive Streamlit dashboard.

## Objectives
- Analyze COVID-19 data using Python.
- Perform data cleaning and exploratory data analysis.
- Identify countries with the highest confirmed cases.
- Visualize COVID-19 statistics using charts.
- Build an interactive dashboard using Streamlit.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Jupyter Notebook

## Project Features
- COVID-19 data analysis
- Country-wise case statistics
- Total confirmed cases, deaths, recoveries, and active cases
- Interactive country and WHO Region filters
- Data visualization and charts
- Filtered dataset download

## Installation and Execution

### 1. Clone the Repository

```bash
git clone https://github.com/Arya-gunji/COVID-19-Data-Analysis-and-Visualization.git
```

### 2. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit Dashboard

```bash
streamlit run app.py
```

## Dataset
The project uses `country_wise_latest.csv`, containing country-wise COVID-19 statistics.
